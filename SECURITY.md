# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 1.0.x | Yes |
| Earlier versions | No |

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in a public issue. Use GitHub's private vulnerability
reporting or security-advisory workflow for this repository to contact the maintainers with:

- the affected component and version;
- reproduction steps or a proof of concept;
- the expected impact; and
- any known mitigations.

The maintainers will acknowledge a complete report, investigate it, and coordinate disclosure and
remediation based on severity. This prototype currently uses plaintext gRPC and must not be exposed
to untrusted networks or used for sensitive production data.
